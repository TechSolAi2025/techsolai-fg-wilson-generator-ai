Pages 55–56 contain image-only fault tables; page 55 has enough surrounding text to evade a text-length-only detector. Visual inspection caught this. Seventeen table rows were transcribed with source-hash locking. Pages 2, 79, 80 and 81 contain only blank/notes material. Image-bearing pages are flagged even when the text layer is strong. An image flag records the review obligation; it does not mean all content on that page is unusable. No weak page is silently discarded.

Printed footer digits appear twice in the text layer. The original raw text is retained; the separate printed-page field records the visually confirmed footer (2–81), with no number inferred for the cover. The source page images/contact sheets are local inspection artifacts, not alternative authoritative manuals.

FG100 icon-dependent instructions, diagram-dependent lifting instructions, illustrative plate/declaration data and identified source ambiguities are quarantined via source_review.json. Transcription and visual review are agent-performed; independent technical QA remains outstanding.
